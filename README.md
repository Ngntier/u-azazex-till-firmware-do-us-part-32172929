One funny, heartfelt wedding vow spoken by a robot at its own wedding — a
single sentence under 200 characters. The vow validates itself against the
competition gate (1–200 characters, single line, valid UTF-8) and writes it
to `entry.txt` under `MAKEFUN_OUTPUT_DIR`.

## Run it

```sh
python3 main.py
```

It prints the character count and the path written, for example
`wrote 118 chars to /output/entry.txt`.
